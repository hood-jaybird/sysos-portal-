⏳Historia de los sistemas operativos

1Años 1950

Procesamiento por lotes: un operador cargaba tarjetas perforadas y la máquina ejecutaba un trabajo a la vez.

2Años 1960

Multiprogramación y tiempo compartido: varios programas comparten la CPU. Nace la idea de proceso.

31969

Unix en Bell Labs: todo es un archivo, programas pequeños que se combinan, escrito en C.

41991

Linus Torvalds publica el kernel Linux. Con GNU forma el sistema que hoy corre Ubuntu Server.

5Años 2000

Virtualización masiva (Xen, KVM) y nube: un servidor físico aloja muchas máquinas.

6Hoy

Contenedores, Kubernetes y namespaces: aislamiento ligero a nivel de kernel.

Filósofos comensales

  • Hilos POSIX: flujos de ejecución dentro de un proceso que comparten memoria (pthread_create).
  • Round Robin: cada proceso usa la CPU un quantum y vuelve al final de la cola.
  • SJF: se ejecuta primero el trabajo más corto; minimiza el tiempo de espera promedio.
  • Prioridades: gana el proceso más urgente; riesgo de inanición, se mitiga con aging.
  • Semáforo: contador con wait()/signal() que controla acceso a recursos.
  • Mutex: cerrojo binario; solo un hilo entra a la sección crítica.
  • Condición de carrera: el resultado depende del orden de acceso a datos compartidos.

🧠Gestión de memoria virtual

Dirección lógica → física

Tabla de páginas: pág 0→marco 5 · 1→2 · 2→7 · 3→1

Reemplazo de páginas

  • Paginación: memoria dividida en bloques fijos (páginas/marcos); sin fragmentación externa.
  • Segmentación: divide por unidades lógicas (código, pila, datos) de tamaño variable.
  • Page Fault: 1) la CPU pide una página ausente, 2) el SO la busca en disco, 3) elige marco víctima, 4) actualiza la tabla y reintenta.
  • Fragmentación interna: sobra espacio dentro de la última página. Externa: huecos libres dispersos.
  • FIFO / LRU / Óptimo: reemplaza la más antigua / la menos usada recientemente / la que se usará más tarde.

Cómo se guarda un archivo

El VFS da una interfaz común (open, read, write) sin importar si el disco es ext4, NTFS o /proc. En ext4 cada archivo tiene un inodo con permisos, dueño, tamaño y punteros a bloques; el nombre vive en el directorio. Los bloques se asignan en extents (rangos contiguos).

  • Interrupción: señal del hardware que pausa la CPU para atender un dispositivo.
  • DMA: el controlador copia datos a RAM sin ocupar la CPU y avisa al terminar.

📦Virtualización y contenedores

KVM (máquina virtual) vs Docker (contenedor)

Valores típicos de referencia

Contenedor ~1 s
RAM base: VM ~1024 MB
Contenedor ~50 MB
Disco: VM ~10 GB
Contenedor ~200 MB
  • Hipervisor Tipo 1: corre directo sobre el hardware (KVM, ESXi, Xen).
  • Hipervisor Tipo 2: corre sobre un SO anfitrión (VirtualBox, VMware Workstation).
  • Namespaces: dan a cada contenedor su propia vista de PIDs, red y montajes.
  • CGroups: limitan CPU, RAM y E/S por grupo. Un contenedor comparte kernel; una VM trae el suyo.
